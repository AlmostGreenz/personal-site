URL Jumper - Chrome Extension

Software
I am happy to announce the release of URL Jumper, a Google Chrome extension developed by Brian (Wei Hao) Ma and myself. URL Jumper allows jumping to URLs using customizable names.

For instance, the gaming platform Steam has a sub-page dedicated to the redemption of game keys. This page is not easily accessible, requiring a number of clicks to reach. Using URL Jumper, one can simply map the word "redeem" to the redemption URL, and then they simply have to press the shortcut key ALT+M or ALT+N and type "redeem" to reach the page.

I am excited to see how others use URL Jumper in their day-to-day web browsing!
